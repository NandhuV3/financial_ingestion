# 008-prompt-registry.md

# Purpose

Prompt Registry is the governance layer for all LLM-generated artifacts.

Every production prompt must be:

- Versioned
- Auditable
- Reproducible
- Rollbackable
- Deployable independently

Prompts are treated as code.

LOCKED.

---

# Core Principle

Prompts are platform assets.

They are not files inside source code.

They are governed resources.

Every artifact generated by an LLM must record:

- Prompt ID
- Prompt Version
- Model Provider
- Model Version

This enables:

- Replayability
- Auditability
- Regression Analysis
- Rollback

LOCKED.

---

# Registry Responsibilities

Prompt Registry owns:

- Prompt Storage
- Prompt Versioning
- Prompt Activation
- Prompt Rollback
- Prompt Lineage
- Prompt Evaluation Metadata

Prompt Registry does NOT own:

- Artifact Generation
- Model Execution
- Business Logic

LOCKED.

---

# Prompt Lifecycle

## Stage 1

Draft

Prompt is created.

Not executable.

---

## Stage 2

Candidate

Prompt ready for evaluation.

Cannot generate production artifacts.

---

## Stage 3

Evaluation

Harness runs.

Comparison performed.

Regression report generated.

---

## Stage 4

Approval

Human review required.

No automatic activation.

LOCKED.

---

## Stage 5

Activation

Prompt becomes production version.

Activation record written.

---

## Stage 6

Archive

Old versions retained permanently.

Never deleted.

LOCKED.

---

# Prompt Activation Workflow

```text
Draft
   ↓

Candidate
   ↓

Evaluation
   ↓

Human Review
   ↓

Activation
   ↓

Production
```

No shortcut paths exist.

LOCKED.

---

# Evaluation Requirement

A prompt version cannot become active without evaluation.

Required before activation:

- Structural Validation
- Grounding Validation
- Consistency Validation
- Regression Validation

LOCKED.

# Regression Blocking

Prompt activation is blocked when:

```text
Structural Score ↓ beyond threshold

Grounding Score ↓ beyond threshold

Consistency Score ↓ beyond threshold

Completeness Score ↓ beyond threshold
```

Thresholds are configurable.

Blocking is automatic.

LOCKED.

---

# Prompt Rollback

Rollback is first-class.

Not emergency-only.

---

## Rollback Flow

```text
Current Version
       ↓

Select Previous Version
       ↓

Activate Previous Version
       ↓

Write Activation Record
       ↓

Trigger Invalidation
```

Rollback never deletes versions.

LOCKED.

---

# Model Migration Governance

Prompt Registry also tracks model migrations.

Example:

```text
GPT-5.5
   ↓
GPT-6
```

Migration requires:

- Evaluation
- Comparison
- Approval
- Activation Record

Model changes are treated like prompt changes.

LOCKED.

---

# Artifact Reprocessing Rules

When a prompt activates:

All artifacts generated using prior versions become stale.

Example:

```text
Structured Intelligence Prompt v4
          ↓
Structured Intelligence Prompt v5

Invalidate:

Structured Intelligence
Company Knowledge
Business Signals
Quarter Understanding
Investor Intelligence
Partner Domain
```

Invalidation handled by Dependency Index.

LOCKED.
