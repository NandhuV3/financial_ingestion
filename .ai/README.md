---

## Principles

- Architecture is the source of truth.
- Never redesign architecture.
- Never bypass Layer Ownership.
- Never duplicate architecture documentation.
- Read only the documents required for the current task.
- Keep changes incremental.
- Prefer review before refactoring.
- Stop and ask when requirements are unclear.

---

## Workflow

1. Read AGENT.md
2. Read the relevant architecture specification.
3. Follow the implementation workflow.
4. Implement only the requested scope.
5. Review against Engineering Standards.
6. Commit small, focused changes.
